# Veo Animation Prompts

Use these prompts with the matching keyframe images in `assets/generated/video/03-keyframes/`.

General settings:

- Duration: 5-6 seconds per clip.
- Aspect ratio: 16:9.
- Use image-to-video.
- Add voice over and subtitles later in CapCut/Premiere.
- Avoid asking Veo to create readable UI text or long dialogue.

Global instruction to append when needed:

```text
Keep the same anime character identity, same outfit, same composition, and same art style. Do not redesign the characters. Do not add readable text. Smooth cinematic motion.
```
